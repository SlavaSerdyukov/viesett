# Viesett preliminary DPIA / risk assessment

M6 scoped addition: HttpOnly browser sessions improve reload reliability but introduce ambient cookie authentication. Exact Origin plus per-session CSRF headers protect mutations; SameSite/Secure/host-prefix flags, short parent-bounded validity, rotation/revocation and owner checks reduce exposure. No raw bearer is persisted in JavaScript storage. Tests cover these controls; actual deployment/TLS/operator/retention review remains necessary.

Real-document evaluation requires entitled, minimized material in a separate private environment. The offline harness has no network/provider/account client, uses the bounded local parser, and emits aggregates without source names/text/values. No authorized real corpus was available, so accuracy/OCR frequency and actual buyer comprehension remain unknown. This addition changes no basis or processor role and does not close prior public/private-beta legal or operational gates.

## M4 scoped addition — 2026-11-12

Co-ownership minutes can expose third-party attendance, debts, disputes and personal circumstances. M4 therefore extracts only bounded property/entity fields, strips free prose into controlled categories, keeps recognized M4 artifacts as normalized facts/locators, and excludes irrelevant contacts, banking and attendees from structured models/API/logs. Source PDFs and earlier/M3/UNKNOWN full-text artifacts can still contain incidental data: source-linked deletion, purpose restrictions and operational rights/restriction review remain necessary. Wrong unit association, false project merges, missing periods and cost-key uncertainty are accuracy risks; exact association, explicit states, conservative reconciliation, dated observations, versioned checks and unknown/blocked estimates reduce them. No amount-based score, automated sending or new AI/processor exists. Public-beta residual-risk assessment remains pending.

## M5 scoped addition — 2026-11-12

New exposure surfaces are anonymous address preview, a development browser credential bridge and a consolidated private projection. Preview has a dedicated bounded limiter, no private database persistence and independent official-ID revalidation when a dossier is created. The optional bootstrap requires non-production opt-in, loopback peer, configured Origin, random short-lived credentials and a strict limiter. Headers carry private authorization; no cookie session or browser persistent token storage is introduced. Explicit CORS, safe error bodies and owner-scoped APIs remain in force.

Consolidation can mislead if generations, source authority or conditional requirements are mixed. Source-signature/owner-lock checks, current-only bounded DTOs, explicit unavailable/stale/conditional states and separate completeness/findings address this risk. The private Blob viewer, source links and local print require the same ownership checks. There is no external viewer, analytics/replay or automatic sharing. Automated selected-page accessibility/flow checks do not establish broad usability or production safety. Shared multi-worker rate limiting, trusted-proxy deployment, reviewed public transparency, final browser sessions, real document accuracy, rights/restriction operations and the prior production gates remain unresolved.
