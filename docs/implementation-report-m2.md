1. **Areas changed:** domain, persistence, property services/API, official integrations, optional smoke CLI, additive migration, source/privacy docs, deterministic tests, CI and lockfile. Authentication, storage, upload safety and optional AI foundations remain. Shared Schema placement changed only to avoid an export typing/import cycle.
2. **Data/migration:** PropertyResolution, current PropertyIdentity, PropertyBuildingUnit, PropertyBuilding, multiple PropertyParcel rows, PublicEnrichmentRun and HeritageObservation; evidence provenance/lifecycle fields. Revision `da321bc669fb` follows unchanged `5e1e917449ce`. Provenance CHECK constraints are explicitly migrated.
3. **Resolution domain:** typed official objects, native geometry/CRS, separate input query/canonical address, explicit progress/resolution/ambiguity/missing/failure states. Structural current identity coexists with validated normalized resolution history; no raw upstream archive.
4. **GRAR strategy:** v2 interactive reads only, without v1/extract, scraping or a home-grown address parser. Prefer documented address navigation; fall back to documented relationship filters. Revalidate official identifiers/namespaces and parent/address relationships.
5. **Search:** `GET /v2/adressen/zoeken?query=…&resultType=Address&status=inGebruik&limit=6`. Only NFC/whitespace preprocessing. Official fuzzy search handles input/bus components. One usable address or a unique full canonical-string match is automatic. [Reviewed contracts](integrations/grar.md) are pinned to provider-owned public implementation revisions.
6. **Units/buildings/parcels:** realized private-unit candidates; common/shared function excluded; building must list selected unit; parcels must confirm selected address. Preserve all returned realized parcels/CaPaKeys. Missing relations remain partial. No ownership, year, condition, property type, valuation or conformity inference.
7. **Ambiguity:** no first-result selection. Small normalized choices, explicit truncation, independent revalidation of supplied IDs. Missing unit detail cannot make another unit automatically unique. Bounds: six search suggestions, twenty inspected unit candidates, three relation pages/100 IDs; exceeded bounds do not silently drop facts.
8. **Evidence:** OFFICIAL/PUBLIC_REGISTRY facts carry provider, source identifier/URI, version/retrieval and locator. Raw input is never official. Stable namespaces: `property.address.*`, `property.building_unit.*`, `property.building.*`, `property.parcel.*`, `property.heritage.*`. DB checks reject inconsistent authority or incomplete provider provenance.
9. **Refresh/versioning:** changed values/source versions create successor observations and expire previous current rows; removed facts expire without deleting history. Unchanged facts update last-seen metadata without duplicates. Current evidence is default; history is explicit/exported. Failed sources preserve successful data with staleness. Generations/revisions reject late or wrong-property results; snapshot reads serialize with mutations to prevent mixed identities.
10. **Heritage:** documented `GET /zoekdiensten/afbakeningen`, all categories, original ID/URI/title/type and meaningful matches preserved. Designations retain published protected/established labels; scientific inventory remains separate, never one boolean. Missing legal status stays null. Building footprint is the current match area; missing area is explicit NOT_APPLICABLE, not “no heritage.”
11. **Flood:** no authoritative supported automatic P/G endpoint was confirmed. Implemented manual Waterinfo/per-CaPaKey links, null scores and no backend score request. Typed contract rejects automatic AVAILABLE/scores. No WMS colors, guessed A–D classes, hazard conversion or private endpoints.
12. **Attribution:** persisted source-run credits, references, terms links and retrieval times. Literal metadata credits: `Bron: Digitaal Vlaanderen` and publisher `Onroerend Erfgoed`. Future object-specific conditions must remain visible; no endorsement or comprehensive commercial-license approval is claimed.
13. **HTTP:** connect/read/write/pool 2/4/2/1 seconds; operation budget 20 seconds; two attempts default, at most three; GET only; exponential backoff and bounded Retry-After; one request/provider and 350ms minimum gap; 2 MiB decoded-response cap. Redirects/proxies disabled. Safe codes replace provider bodies, addresses, secrets and exception representations.
14. **SSRF:** exact official hosts/path families, HTTPS/default port, no credentials/fragments/encoded/dot paths. Documented alias normalized to one request host. Pagination retains/reapplies the address filter and rejects changed relationships. Provenance URIs are never automatically fetched.
15. **Privacy:** scoped lookup purpose/categories/recipient/retention additions to existing drafts. Only address/IDs or selected area leave the service; no account identity/documents. Government roles/transfers remain open. Notice `2026-11-11-m2` changes currentness without rewriting old texts/acknowledgements; upload policy remains unchanged. Existing version tests now compare actual current policy versions instead of hardcoding M1.
