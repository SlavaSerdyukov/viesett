Six-section dossier navigation; completeness, missing information and findings remain distinct. Minimal address-first start screen; no fabricated logos/statistics, pricing, score/gauge, chatbot or fear-based copy. [Design notes](frontend/design.md).
7. **Property preview:** Dedicated public `POST /api/v1/property-preview` composes existing bounded M2 resolution into RESOLVED / NEEDS_SELECTION / NOT_FOUND / UPSTREAM_UNAVAILABLE. No private workspace or anonymous persistent history is created. It returns safe normalized official fields, attribution and manual flood links. Heritage is explicitly unqueried in preview, never presented as a negative match. Missing box labels are explained rather than invented; private creation independently revalidates official IDs/relationships.
8. **Preview security/rates:** Separate default **five requests/minute** network-peer limiter with at most 1,000 ephemeral hashed keys; existing provider timeout/host/path/rate/body safeguards retained. Private fields are rejected and workspace/document/evidence APIs remain authenticated. Route logic ignores forwarded headers; trusted-proxy configuration/shared multi-worker limiting remain deployment work. Official source failure is distinct from an invalid/not-found address. No preview cache means deliberate second validation on creation. [Architecture](product/architecture.md).
9. **Authentication bridge:** Existing bearer security remains authoritative. Operator-provisioned token entry plus optional explicitly enabled loopback-only development bootstrap; random one-hour token, configured Origin, five bootstrap requests/minute, no universal credential. Production forbids development/demo flags. Token and query state stay in page memory; disconnect/reconnect clears private cache, reload requires the original token again. No localStorage/sessionStorage credential, cookie session or new CSRF-dependent mutation mechanism. Public signup/recovery/final browser auth deferred.
10. **BuyerDossierSnapshot:** Owner-only `GET /api/v1/workspaces/{id}/dossier` returns `buyer-dossier:1.0.0` explicit Pydantic responses: property/source states, requirements/completeness, documents, current findings, co-ownership summary, questions, evidence/citations and update time. It composes existing authority, never becomes a new source. Locked source signatures before/after idempotent evaluation reject mixed generations (bounded retries then safe conflict). Current association is recalculated against current identity. Limits/truncation are explicit; no raw source/page text, storage keys, histories or evaluation input archive. Synthetic five-document sample: approximately **86 KB** uncompressed.
11. **Completeness:** Unweighted usable REQUIRED information plus established applicable co-ownership components; completed/applicable counts and percentage are exposed. Unresolved CONDITIONAL items are excluded and counted separately. Missing/OCR/mismatched/unusable/expired input does not satisfy a required item. Zero denominator yields null percentage, not 100%; states distinguish progress, missing applicability, incomplete and complete. A usable adverse certificate can complete information and still create a finding. [Calculation](dossier/completeness.md).
12. **Overview:** Canonical property/source status/date, completeness, attention findings, missing information, official facts, available works/exposure and next actions. User input is separate from official identity. Flood remains manual with no score; source unavailable/stale/partial states stay visible. Unresolved properties can be checked and confirmed inside the same dossier without creating another workspace.
13. **Documents:** Universal PDF drop/select control, current attestation, real combined upload/safety/analysis state, effective kind, association, summary, dates, retry/view/delete. Requirements preserve applicability, presence and explanations; conditional unknown is not unconditional missing. Missing-document requests use existing deterministic editable drafts and Copy only. Deletion requires confirmation and refreshes the dossier.
14. **Findings:** Meaning-based groups (identity, energy, asbestos, electrical, soil, co-ownership, documents, consistency), existing severity with plain labels, concise explanations and clarification actions. Source/rule/page/version details are expandable. Codes are secondary. A data gap remains missing information and never becomes a blocked purchase or buy/no-buy recommendation.
15. **Co-ownership:** Available VME/ACP identity, Article 3.94 components and period gaps, funds, AGM works, capital calls, litigation and proportional exposure are displayed from current M4 output. No-data state is explicit. Date/lot/currency and different fund/call meanings remain intact. The product summary omits internal evaluation histories, hashes, duplicate findings/questions and raw inputs.
16. **Questions:** Deterministic seller/agent/syndic/notary grouping, reason and source references, per-question/all copy. Exact question-to-finding matching uses conclusion identity rather than sharing only a rule code. No recipient, mailbox, send button, SMTP or automatic follow-up.
17. **Evidence:** Current facts grouped Official / From documents / Derived-inferred / Unverified with readable label/value/source/date. Source effective date is distinguished from recording date. Derivations retain inferred status and assumptions. No arbitrary raw JSON or storage keys. Additional bounded citation metadata keeps visible claims traceable even when their evidence falls outside the 500-fact page; truncation remains explicit.
18. **Upload/analyze orchestration:** Product intake delegates to existing attestation, size/media/safety/private-storage logic, then automatically analyzes only READY PDFs with existing M3/M4 behavior. Quarantined files do not enter analysis. Response returns the refreshed snapshot; mutations update/invalidate the relevant query. Refresh coordinates deterministic evaluations plus optional public enrichment without destructive PDF reprocessing. Active polling is bounded and stops at terminal states or the age limit; no WebSocket.
19. **UNKNOWN/OCR:** Normal supported files need no type choice. UNKNOWN can use existing manual-kind correction/history; retry does not silently replace a prior manual choice. Scanned PDFs explicitly say automatic reading is unavailable and can be kept/deleted. Partial/unsupported/unparseable/failed states remain distinct. No OCR SaaS, false progress percentage or whole-document-understanding claim.
20. **Exposure UX:** M4 exact derivations are presented as estimates with project budget, explicit funding, remaining basis, applicable rational share, assumptions and citations. The fictional sample shows €120,000 budget, €40,000 explicit project funding, 75/1000 share and **€6,000** proportional remaining-basis estimate. Unknown allocation prevents a false precise number; general reserves are not silently deducted. Legal buyer/seller responsibility remains **Not determined**.
21. **Citations/PDF:** Reusable citations link public official references or owner-only private document routes. Only the selected PDF is fetched with Authorization into a temporary Blob URL; abort/revoke cleanup runs on close. `#page=N`, visible target-page text and download provide bounded deep-link behavior. No public object URL, external viewer, automatic source fetching or coordinate-highlighting claim. Browser engine/page-jump limitations remain visible.
22. **Print/notary:** “Prepare for notary” opens the same authorized current projection, with property, completeness, unresolved findings, missing/conditional information, document/co-ownership summaries, estimates/assumptions, questions, source list and attribution/terms. [Print boundaries](dossier/print.md).
