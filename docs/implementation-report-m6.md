10. **Session architecture:** operator-provisioned bearer exchange creates a random opaque short-lived server session; only its hash is stored. HttpOnly, SameSite=Strict, host-only Path=/ cookie, Secure and `__Host-` in production. Default eight hours, maximum 24, bounded by parent token expiry. Account/parent ownership FK, rotation, parent deletion/expiry and server revocation apply. Reload restores session/CSRF; no bearer/session secret is persisted in JavaScript storage. Original API-token authority remains usable/revocable and is not consumed by exchange. No public signup/password/email authentication. [Design](private-beta/sessions.md).
11. **CSRF:** every cookie-authenticated mutation requires exact allowed Origin plus session synchronizer token/header; cross-site Fetch Metadata is denied. SameSite and credentialed CORS supplement those checks. Exchange is independently Origin-protected. Explicit invalid bearer authorization never falls back to a valid cookie. Oversized/non-ASCII/missing/wrong CSRF values fail safely.
