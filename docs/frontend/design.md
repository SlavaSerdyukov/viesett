# Interface and accessibility

The dossier is the main object. A restrained forest/ivory palette, system sans-serif text, serif property headings, spacious cards and source references support a calm review workflow. Findings, missing information and completeness are visually separate. No score/gauge, chatbot, testimonials, invented statistics or fear-based copy exists.

Desktop uses a six-section left navigation; narrow screens use a compact horizontally scrollable navigation. The same document upload, property selection, findings, questions and print actions work at mobile widths. Status uses words as well as color. Native labels, semantic main/navigation/headings, visible focus, a skip link and native modal dialogs support keyboard and screen-reader use. Small text contrast was increased after an automated audit found insufficient contrast.

Selected Overview scenarios are checked by axe against WCAG A/AA rules inside the deterministic browser suite. Passing these selected checks is not a complete accessibility certification. Browser/device PDF behavior, long or unusual source material and real user usability still require private evaluation.

Sources are ordinary keyboard-accessible links. Document citations open only an authenticated Blob-backed source view, with target page explicitly indicated. Rule codes appear in expandable details, not as primary titles. Original source/effective dates are distinguished from fact-recording dates. Amounts retain their currency; estimates expose applicable shares, project funding, assumptions and undetermined legal responsibility.
